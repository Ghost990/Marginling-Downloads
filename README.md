# Marginling Android

A Marginling egy EPUB-olvasó, ahol minden könyvhöz saját laplakó tartozik.

[**A legfrissebb Marginling APK letöltése**](https://github.com/Ghost990/Marginling-Downloads/releases/latest/download/Marginling.apk) · [Korábbi verziók](https://github.com/Ghost990/Marginling-Downloads/releases)

Android 8 vagy újabb szükséges. A telefonon nyisd meg a letöltött APK-t. Ha az Android engedélyt kér, engedélyezd a telepítést annak az alkalmazásnak, amelyből megnyitottad a fájlt.

Új verziónál töltsd le az APK-t ugyanerről a linkről, és válaszd a **Frissítés** gombot. A könyvek és az olvasási hely megmaradnak, ha az előző tesztkiadásra telepíted.
